## 阅读结构

两个同级入口为「内窥镜专用方法」和「通用三维重建方法」。各自按数据集切换；无可比记录时明确提示，不以 smoke 或其他模型分数补齐。主表只列 PSNR、SSIM、LPIPS 和深度 MAE。配置/训练预算收在方法名称下面。

已有原始数据、历史四组表格、独立深度评价、pilot、完整协议、方法状态及全部旧下载文件保留。补充内容默认折叠，旧锚点可以打开所属类别/数据集与折叠项。关闭 JavaScript 后所有主表仍可阅读；键盘左右键/Home/End 可切换标签。

## 标色规则

红色 + 数字 1 为第一名，蓝色 + 数字 2 为第二名。每个表格、每个指标独立使用原始精度比较，等值并列（下一不同值为第二名），不按页面舍入值排序。PSNR/SSIM 越大越好，LPIPS/MAE 越小越好。少于两条有效记录不排名。

通用模型表包含「输入图像直接平均」这个非三维对照，且对照参与标色；它不是三维重建模型，MAE 不适用。SCARED pilot 的验证与测试不是同一划分，不互相排名。历史 EndoNeRF/EC 保留不同训练预算；标色只描述记录值，不是等预算、公平性或几何准确性结论。组织块 AlexNet LPIPS 不与全图 SqueezeNet LPIPS 混排。

现有汇总没有报告可加入主表的深度 MAE，JSON 使用 null，CSV 留空，页面显示 —。不将 AbsRel、RMSE、视差 EPE、覆盖率、曝光敏感性或其他协议的 MAE 当作这一项。

## 构建与维护

继续执行 `python3 scripts/build.py`。原生成器先输出全部原始数据和旧版页面，然后 `scripts/reproduction_rankings.py` 仅重组复现页面，生成 `data/four-metric-view-20261008.csv/json`，不改写输入数据或原下载文件。

只需运行 `python3 scripts/check_reproduction_rankings.py` 即可只读检查全精度来源、第一/第二名、并列、缺失值、对照、协议分组和页面内所有本地链接。新增实验/数据集后要同步审查显式分组及覆盖断言，不要把新协议自动并入旧表。

新增 CSS/JS 仅在复现页加载，其他页面不受影响。本次未访问实验服务器、未新增实验或重新计算模型指标。
