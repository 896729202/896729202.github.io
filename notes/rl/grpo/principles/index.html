实测诊断：Reward 上升，正确率为什么没有明显提高？

记录日期：2026-10-10。本文把真实实验汇总与教学数值例子分开，围绕数学回答的 GRPO 训练说明机制与诊断方法。

**来源与边界：**下列实测数字依据作者提供的实验汇总，本次未独立读取服务器上的训练日志、逐题预测或权重。算法机制参考 DeepSeekMath 原论文第 4.1 节。教学例子是人为构造的算例，不是实际训练轨迹；实现的标准差、长度归一化、KL 系数和优化器设置须以训练代码为准。

从组内奖励到参数更新

GRPO 对同一道题从旧策略采样 G 个回答，分别评分。结果奖励场景下，每个回答得到一个组内相对优势，通常广播到该回答的生成 token；不需要另外训练 Critic 来估计这个基线。这里只讲结果奖励，不把过程奖励混在一起。

1. 奖励归一化与 Advantage

设奖励为 R₁…R_G，组均值为 μ，标准差为 σ。常见稳定实现为：

A_i = (R_i - μ) / (σ + δ)

δ 是防止除零的小数。A 是 Advantage（优势）：比本组平均好为正，比平均差为负。它不是绝对正确率，也不是当前 token 的独立真实贡献。优势在反向传播中通常视为常量，不对评分器和组统计反向求导。

**教学例子：**正确奖励 1，完整格式奖励 0.2。四个回答都符合格式，其中两个正确：

回答正确性格式总奖励 RR − μA（忽略极小 δ）
110.21.20.51
210.21.20.51
300.20.2−0.5−1
400.20.2−0.5−1

逐步验算：μ=(1.2+1.2+0.2+0.2)/4=0.7；采用总体标准差，σ=√[(0.25+0.25+0.25+0.25)/4]=0.5。因此 A=(1,1,−1,−1)。若采用样本标准差，σ≈0.57735，A≈±0.86603；数值不同，方向相同。

共同的格式分数 0.2 在减均值时抵消：它提高原始 Reward，却没有给这组回答增加区分信号。若格式分数在回答间不同，则会改变优势，不能一概说格式奖励不影响学习。

2. 策略概率比与 Clip

对某个已采样 token，在相同题目和回答前缀下，记旧策略概率 p_old、新策略概率 p_new：

ρ = p_new / p_old

它是当前策略与采样旧策略之比；参考策略 Ref 是 KL 的锚点，职责不同。一般 GRPO 使用逐 token 概率比，这里没有把整句概率直接拿来相除。

设裁剪范围 ε=0.2，单 token 的奖励代理目标为：

J = min(ρ × A, clip(ρ, 0.8, 1.2) × A)

正优势且概率已增加过多，第一类收益封顶；负优势且概率已降低过多，改善收益也封顶。负优势回答的概率反而升高时，目标仍惩罚这种变化。Clip 并不把概率或参数硬锁在区间内，也不是梯度范数裁剪。

3. Loss、梯度与更新：一步算到参数

最大化 J 等价于最小化 L_policy = −J。整个训练还要聚合组和 token，并可能加上 β × KL；下例暂不加 KL，只看单个未裁剪 token 的局部贡献。

**教学例子：**用一个标量 w 表示 token 相对其他 token 的 logit，p=sigmoid(w)，固定 p_old=0.2、A=+1，当前 p=0.22。

  1. w=ln(0.22/0.78)≈−1.26567；ρ=0.22/0.2=1.1；J=1.1，L=−1.1。
  2. dp/dw=p(1−p)=0.22×0.78=0.1716。
  3. dL/dw=−(A/p_old)×dp/dw=−(1/0.2)×0.1716=−0.858。
  4. 用普通梯度下降、学习率 η=0.1：w_new=w−η×dL/dw≈−1.17987。
  5. p_new=sigmoid(w_new)≈0.23508，ρ_new≈1.17540，L_new≈−1.17540。Loss 更小，正优势 token 的概率增加。

若 A=−1，当前点的梯度变成 +0.858，更新后 w≈−1.35147，概率≈0.20563，方向是降低概率。若 A=+1 且当前 p=0.26、ρ=1.3，裁剪分支 J=1.2 为常数，该项局部梯度为零。边界点的导数需按实际框架处理。

真实大模型使用共享参数、softmax、多 token、多回答与 Adam 等优化器，上述标量更新不代表某个 token 概率在真实训练中必然单调变化。Loss 数值决定目标高低，梯度决定更新方向和局部速度；负 Loss 完全正常，不能仅比较 −1.3 和 −1.43 就判断谁更新更快。

4. KL 和梯度下降各自做什么？

KL 约束当前策略偏离参考策略的程度；Clip 限制相对旧策略的奖励代理目标过度改善；梯度下降负责根据总 Loss 更新参数。它们解决不同问题。

用于理解的 KL 例子：当前二元分布 (0.22,0.78)，参考分布 (0.20,0.80)，则完整分布的 KL(current || ref)=0.22 ln(1.1)+0.78 ln(0.975)≈0.00122035。若 β=0.1，总 Loss 在该点约为 −1.1+0.00012203=−1.09987797。加 KL 后还必须对 KL 项求梯度，不能沿用上面忽略 KL 的更新数值。

这是完整二元分布的教学计算；原论文使用采样估计形式，不能把此数值当作实际训练日志中的 token KL。本轮汇总没有给出 β 或 KL 曲线，不能据此断言实际 KL 强弱。

问题一：奖励方差为零，为什么训练信号可能消失？

**教学例子：**四个奖励全为 1.2，μ=1.2、σ=0，加入 δ 后每个 A 都是 0；四个奖励全为 0.2 也是同样结果。没有稳定处理时直接除零会产生未定义值，而不是自动获得有效优势。

A=0 时，ρA 和裁剪项都是 0，奖励代理目标对策略参数的梯度为零。这组全对样本不再提供“谁更好”的相对信号；全错组也没有正样本可以强化。消失的是该组的奖励策略梯度，不一定是总梯度：KL、其他非零优势组、共享参数及优化器状态仍可能引起更新。

**实测观察：**原始 G=4 的零方差组占 73.75%。这提示大量组缺少奖励区分，但不能直接说“73.75% 算力完全浪费”。零方差也不等于回答文字相同：不同推理都可能全对或全错；反之，固定评分器下完全相同的回答通常同分。

问题二：增加采样次数，为什么不一定提高正确率？

**教学模型：**假定各次采样独立、每次答对概率固定为 p，且只有二元正确性奖励。mixed 概率为 1 − p^G − (1−p)^G。例如 p=0.1 时，G=4 为 34.38%，G=8 约 56.95%。这说明组数增加可以更容易遇到对错混合，没有说明训练后的 p 一定变大。实际回答相关，且有格式奖励，该公式不能直接拟合上述实测比例。

**实测观察：**G=8 将 mixed 比例从 26.25% 提到 37.50%，但仍是 234/500。可用比较信号变多与学会泛化是两件事。新增样本可能只是容易题的重复正确回答，难题仍全错；也可能生成不同但都错误的推理。温度太低会重复，太高可能增加无效输出。应同时查看组内正确数、去重率、截断率和更新幅度。

增加 G 也增加生成成本。比较时需要报告题目数、生成 token 总量、更新次数与预算；同题目数和同计算预算是两种不同对照。现有汇总不足以判定哪种配置的训练效率更高。训练 G、测试单次正确率、pass@k 和有选择器的 best-of-k 应分别报告。

问题三：如何区分奖励、采样与上游 SFT 问题？

先固定测试集、提示词、解码参数、答案解析和评分口径，再定位问题；以下是诊断建议，不是已经执行的新实验。

诊断层要核对的证据更支持该问题的现象下一步验证
奖励设计 / 解析人工复核正确与错误答案，拆开正确性和格式分数，测试等价表达、空答案、标签缺失错误答案获高分，正确答案因解析被判错；Reward 涨而正确性分数不涨修正评分器；固定起点和预算做奖励消融
采样每题正确样本数、奖励 σ、回答去重、温度/top-p、截断、种子多数全错组输出高度重复；温度或 G 改变后首次出现正确候选在训练集或独立诊断集比较采样设置，核算成本和有效 mixed 数
上游 SFT 能力未微调模型、Base SFT、Format SFT 的统一逐题测试及错误类型固定口径下 SFT 后能力下降；合理采样下难题很少出现正确候选检查 SFT 数据质量、答案监督掩码、截断、训练强度和任务混合，先修起点
更新实现 / 约束优势分布、有效 token 掩码、梯度范数、ρ、clip fraction、KL、实际参数变化有非零优势却无有效更新，或大量项被裁剪、KL 强烈主导抽一个 batch 验算 Loss 与梯度，核对冻结、优化器和概率比计算

现有数据更支持的判断是：Format SFT 明显解决了格式输出问题；增大 G 缓解了零方差比例，却没有转化为本轮测试收益；格式奖励消融也没有突破 46.80%。这使“继续增大 G 或微调格式权重”缺少直接收益证据，但尚未唯一定位正确率瓶颈。

判断上游 SFT 是否损伤能力，需要另加未微调模型的同口径对照；215/500 的 Base SFT 本身不能证明损伤。即使某个其他测试曾发现 SFT 退化，也不能把不同题集的百分比混入本表。全错组很多同样不能单独证明模型没有能力，还可能是评分、截断或采样设置的问题。

实验结论与复核清单

Reward 是训练代理指标。共同格式分数、训练题熟悉度和采样分布变化都可能影响其均值；独立测试正确率衡量另一件事。即使只奖励正确性，训练 Reward 上升也不保证测试泛化。组内平均 A 为零也不意味着整组梯度必然为零，因为每个回答的概率梯度方向不同。

本轮可报告：**Format SFT 232/500，GRPO 234/500；G=8 与格式奖励消融均未带来进一步的总正确率提高，尚无显著收益证据。**不能报告“GRPO 已显著提高数学能力”，也不能把结果推广为“GRPO 无效”。

后续复核应保留同一 SFT 权重起点、训练题目与随机种子、采样参数、奖励分项、组内统计、生成预算、KL/Clip/梯度日志以及逐题测试结果。用独立验证集选择设置，最终测试集报告配对差异与多种子波动，才能把观察推进为有证据的因果诊断。
