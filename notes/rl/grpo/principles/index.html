GRPO · 原理

八股文原理

GRPO 先在每条回答内平均，再对回答平均：每条回答等权，长回答的单个 token 权重更小。

符号与优势

以下讨论每条回答只有一个结果奖励的情形：同一回答的 token 共用优势 Ai。

  • G：同题采样的回答数；Ti：第 i 条回答的有效 token 数；Ri：该回答的奖励。
  • Ai：奖励相对同组均值的标准化优势。
  • ρi,t：当前模型与采样时旧模型，在相同上下文下生成该 token 的概率比。
  • Ki,t：相对参考模型的逐 token KL 惩罚估计；β：惩罚系数；ϵ：裁剪范围。
Ai=Ri−mean(R1,…,RG)std(R1,…,RG)
ρi,t=πθ(oi,t∣q,oi,<t)πold(oi,t∣q,oi,<t)

q 是问题，oi,<t 是该回答此前的 token。标准差为零时需处理除零；该组没有相对奖励学习信号，KL 项仍可能产生梯度。

目标函数：看平均系数

将原式两层平均展开，得到等价的最大化目标：

JGRPO(θ)=E[∑i=1G∑t=1Ti1GTi―(min[ρi,tAi,clip(ρi,t,1−ϵ,1+ϵ)Ai]−βKi,t)]

E 对训练问题及旧策略采样结果取期望；旧策略用于概率比，参考模型用于 KL 约束。GRPO 原论文 §4.1

长度带来的影响

下划线系数是 1/(GTi)：每条回答总权重为 1/G，回答越长，单个 token 分到的权重越小。

在优势、概率比等其他条件相同时：

  • 正优势：短回答的单 token 正向更新更强，长回答的有用模式可能学习不足。
  • 负优势：长回答的单 token 惩罚更弱，冗长错误可能抑制不足。

所以不能简单说“GRPO 只偏爱短回答”。长度偏差分析 §3.1
