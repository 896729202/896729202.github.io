# 面试问题汇总

**AI 搜索项目面试追问清单**

## 一、项目到底做了什么

1. 这个项目解决什么具体问题？原来的答案有哪些缺陷：错引、漏引、重复引用，还是文本本身不准确？请各举一个真实案例。
2. 从用户输入 query，到召回视频、生成答案、添加引用，完整流程是什么？主模型、4B 辅助模型、奖励函数分别负责哪一步？哪些只在训练时使用？
3. ★ 你本人具体完成了哪些工作？哪些是其他同学负责的？哪些细节来自你的实际操作，哪些来自团队介绍？
4. ★ 主模型和辅助模型的完整名称、参数规模是什么？模型发布时间是否与项目时间吻合？截图里的 7B／8B 实验与所说的 4B、32B／35B 分别有什么关系？

## 二、4B 模型如何训练、如何提供参考

5. 请完整举出一条 4B 训练样本：输入句子、候选视频信息、参考 ID、生成的 ID，以及对应奖励。ID 是视频库里的固定 ID，还是本次候选列表的序号？
6. ★ 参考答案最初由谁提供？人工标注和三个强模型如何配合？三个模型意见不一致怎么办？一致的答案如何抽检？训练集和测试集如何避免重复或泄漏？
7. ★ “4B 模型准确率约 98%”具体指什么指标？测试集有多少样本、如何构造？为什么这个数字还不足以证明它可以充当可靠教师？
8. ★ 主模型分别生成“支持无线充电”和“不支持无线充电”两句话，能否共用同一份参考视频 ID？4B 模型在什么时候、根据什么输入生成参考？教师出错时如何处理？

## 三、引用奖励与最终评测

9. 参考 ID 为 `[1,2,3,4]`，预测为 `[1,2,5]`：选了几个、选对几个？精确率、召回率、F1 分别是多少？先用中文解释分子和分母。
10. 三个视频内容重复，任何一个都能支持同一句话，参考答案应该怎样标？如果固定标成 `[1,2,3]`，直接使用 F1 会鼓励模型怎样引用？
11. ★ “支持度”和“无冗余支持度”的准确含义是什么？评价单位是句子、引用，还是整条回答？谁判断“支持”和“冗余”？少引用、空引用如何计分？
12. 训练引用奖励使用 F1，最终评测使用支持度和无冗余支持度，这些指标分别衡量什么？为什么 F1 上升不能直接证明业务效果提高？

## 四、奖励究竟怎么计算

13. ★ 文本质量分到底由谁提供：规则、模型评审服务，还是单独训练的奖励模型？输入是否包含用户问题、候选视频资料和主模型回答？它能判断哪些质量问题？
14. 如果文本奖励是 0～10，引用 F1 是 0～1，直接各乘 0.5 是否公平？如何处理尺度、设置权重，并检查某一项是否压过另一项？
15. 格式错误、重复 ID、越界 ID、零命中、参考答案为空时，分别如何给分？截图里的“硬约束＋F1”用于训练 4B 模型，还是用于主模型的引用奖励？
16. 如果只保留引用 F1，没有文本质量奖励，模型可能出现哪些“分数高但回答不好”的行为？例如回答空泛、回避难点、反复说容易找到依据的话，准备如何检测？

## 五、GRPO、DAPO 和 token 奖励

17. GRPO 如何完成一次更新？同一问题生成多条回答后，谁给这些回答打分？奖励如何变成优势值？如果一组回答全部同分，会发生什么？
18. 一条回答有 4 个 token，原始奖励分别为：

    - 方案 A：`[0,0,0,0.8]`
    - 方案 B：`[0.8,0.8,0.8,0.8]`

    不考虑折扣，累计当前位置及后续奖励时，第一个位置的回报分别是多少？为什么“奖励”和“优势值”不能混为一谈？

19. 把文本奖励记在回答末尾、引用奖励记在右括号位置，是否就实现了细粒度训练？后续代码怎样计算回报和优势？是否又把 token 奖励求和、广播成整条回答统一的优势？
20. PPO、GRPO、DAPO 的主要区别是什么？Critic、奖励模型、参考模型分别做什么？你使用的 verl 版本和配置如何实现这些差异，是否只改一个开关就够？

## 六、LoRA 与全参数训练

21. GRPO 阶段具体更新哪些参数？如果使用 LoRA，哪些原始参数冻结、哪些新增参数训练？奖励模型和参考模型是否一起更新？
22. LoRA 加在哪些模块？`all-linear` 表示什么？rank、alpha、学习率分别控制什么？项目实际使用的数值和可训练参数量有没有记录？
23. 为什么选择 GRPO＋LoRA，或者 GRPO＋全参？是否做过对照？如何区分“选择它作为起点”和“实验已经证明它更好”？
24. 是否存在“SFT 用 LoRA，合并后 GRPO 做全参”的多阶段流程？合并 LoRA 具体做了什么？“合并不掉点”是在与哪个模型比较？

## 七、如果模型是 MoE

25. Dense 和 MoE 的区别是什么？MoE 层、路由器、专家网络各自是什么？“总参数 35B、激活参数约 3B”分别表示什么？
26. 微调时更新了哪些部分：注意力、路由器、路由专家、共享专家？如果使用 LoRA，如何确认专家权重真正被覆盖？
27. 冻结路由器参数后，同一个输入的专家选择是否一定不变？为什么上游模块或 LoRA 的变化仍可能影响路由？生成与训练阶段路由不一致时怎么办？
28. 为什么激活参数只有约 3B，不能按一个 3B 模型估算训练显存？全参训练是否意味着每个 token 都经过、更新所有专家？

## 八、算力、实验和研发能力

29. ★ 8 张 H200 对应哪次训练？序列长度、生成并发、训练微批、分片、张量并行、卸载分别如何设置？“57GB”是单卡还是总量、哪个阶段、用什么工具测得？
30. GRPO 的 `n=8` 具体表示什么？改成 16 后，显存和耗时为什么不一定简单翻倍？在固定生成数量或计算预算下，如何比较 n=8 和 n=16？
31. 如何证明无冗余支持度的提升来自新增引用奖励？对照实验改变什么、固定什么？如何排除更多数据、更多计算量或其他配置变化的影响？文本质量是否出现退化？
32. 项目最难的两三个问题是什么？请按“具体失败案例→原因判断→尝试的方案→验证结果”讲清楚。哪些结论有配置、日志、评测结果或可公开材料佐证？
