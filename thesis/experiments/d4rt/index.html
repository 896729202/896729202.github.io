D4RT：渲染诊断与测试集过拟合

直接用测试目标训练，再在同一批目标上测量：新增外观记忆使 7 个公共数据集的平均 PSNR 达到 29.17–32.36 dB；参数微调路线仍未在这些数据集上全面达到 28 dB。

测试目标参与训练与选优这些是过拟合诊断结果，不是独立测试成绩。预测时不用目标 RGB，不代表训练时没见过目标。

固定 A 的输出，每个目标单独学习 RGB 残差网格；按目标身份查询记忆并加回 A。它没有接在 C 后面，也不是原生 D4RT 参数微调。

测试集过拟合 · 新增逐目标记忆模块

所以，“直接预测测试集”需要区分：A、B 是本轮未微调参数的基线；C、D 已使用目标标签训练。C、D 推理时不再读取目标 RGB，但测试目标的信息已经进入权重或记忆。

Hamlyn 的 A 沿用历史估计相机，那个相机估计步骤使用过目标 RGB；渲染纹理仍来自上下文。不能把它称为严格无目标信息的评测。预训练基线也不代表已核验上游预训练数据与本地数据完全无重叠。

02网格渲染与新渲染器有什么区别

网格渲染：先建三维表面，再投影

  1. 从两张上下文图预测深度。
  2. 用内参反投影为三维点，连接成三角面片。
  3. 用外部提供或估计的相机位姿投影到目标视角。
  4. 按深度处理遮挡并贴上上下文颜色；没有覆盖的像素留黑。

新渲染器：反向采样上下文颜色

  1. 由两张上下文图构造时间插值代理，不输入真实目标图。
  2. 把 D4RT 跨时 XYZ 投影相对冻结模型的变化转成二维位移。
  3. 对目标像素，反向查找两张上下文图上的颜色。
  4. 插值并按时间混合；越界采样使用边缘填充。

两者的相机使用、遮挡处理和空洞行为不同。A → C 的变化同时包含换渲染器和训练；C − B 才是在新渲染器内的配对训练增量。较高 PSNR 本身不能证明三维几何更准确。

新渲染器与外观记忆的实现边界

新渲染器输入为［上下文 0、上下文插值代理、上下文 1、上下文 1］。二维采样位置是 identity grid 加相对冻结预测的有界残差，最大约 31.875 像素；64×64 位移网格插值到 256×256。它是本次新增的残差反向渲染器，不是官方 D4RT 的 RGB 解码头。

外观记忆的残差网格从零初始化，用 Adam 对每个目标优化 300 步。先试 64×64，均值不足 28 时再试 128×128；SCARED 预设的 192 追加条件未触发。较低容量版本也保留。这个已测容量结果不是数学意义上的上限。

04为什么原来的 PSNR 较低

这些控制实验解释现有渲染链路的误差，不把读取目标真值的诊断当作可泛化方法。

固定旧目标集的诊断控制；不与扩展集主表混算
检查项观察能说明什么
mask 与 GT_maskEndoNeRF：全帧 23.206；mask 26.134；GT_mask 25.851。EC 两种 mask 均约 13.59。EndoNeRF 两种 mask 相差约 0.283 dB；掩码口径影响分数，但解释不了 EC 的整体低分。
曝光失配EC 原输出做逐通道 GT 仿射亮度拟合：13.006 → 24.816 dB。支持存在显著光度误差。拟合使用目标 GT，仅作为诊断。
覆盖空洞StereoMIS 仅用上下文均值补黑洞：23.062 → 26.509 dB；一个全黑输出为 6.398 dB。原网格渲染的空洞会实质拉低全帧 PSNR。
旧训练与渲染脱节旧三帧输入的第三帧未被时间下采样编码；旧跨时 XYZ 训练未进入 self-depth 刚性贴图。旧 clean/leak 相同不能证明训练无效。该旧实验不进入本页最终表。
宽高比修正 SCARED、StereoMIS、Hamlyn 后，同旧目标分数变化均小于 0.007 dB。本次前后对照未显示显著改善；历史运行环境未完全核实，不作为纯宽高比因果消融。

当前方向是让跨时对应进入渲染、处理曝光和遮挡，并使用匹配的光度训练目标。本轮不使用 GRPO；新增外观记忆只证明允许记住这些目标后可取得高分，未证明几何或新场景泛化改善。

05数据范围、复核与下载

共 1250 目标 / 110 序列：公共数据 1112 / 96，合成对照 138 / 14。这是本轮已定义的抽帧协议，不是磁盘全部原始视频帧。空素材目录、单帧快照、缺少可靠相机对应的 SCARED test8/9 和尚未核对图像—位姿对应的 EndoSLAM UnityCam 未纳入。

主指标：RGB 归一到 [0,1]，全帧 MSE 后计算逐帧 PSNR；先对同序列帧平均，再对数据集内各序列等权。不按方法各自的 coverage、mask 或 GT_mask 筛选，也不是把全数据 MSE 合起来再取一次对数。

1250 个目标的 PNG 分数均独立复算，并核对目标对应、样本集合、权重哈希和聚合方式。每组原生权重至少一个新进程重载样例通过；StereoMIS 全帧版本额外通过全部 36 帧逐像素复核。最终外观记忆版本全部 1250 帧均通过权重重载验证。

常规参数训练和早期外观记忆使用 PyTorch 2.4；StereoMIS 全帧版本、修正网格基线和修正版外观记忆使用 2.5.1。跨版本首次重载曾出现像素差异，同训练环境复核后完全一致。精确复现应匹配各自环境。

权重按数据集保存：原生参数的 best / last、优化器、冻结参考位移，以及外观记忆网格分别归档。本页提供指标与协议下载，模型权重保存在实验工作区。
